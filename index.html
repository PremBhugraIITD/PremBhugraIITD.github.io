Products

Two flagship Mac apps. One covers the session. The other reports the hardware.

01 · Screen lock

Glass Shield

A view-only macOS screen lock. A session-level CGEvent tap blocks input, Touch ID and LAContext confirm the owner, and a hardware tripwire keeps the cover in place.

  • Covers every connected display
  • Owner authentication through LocalAuthentication
  • Works with no network connection

02 · Hardware telemetry

SiliconSense

Native macOS desktop widgets. Live Apple Silicon CPU and GPU load, hinge angle, trackpad force, chassis temperature, and tilt, read through IOKit.

  • Readings stay on the Mac
  • Native WidgetKit surfaces
  • Built for Apple Silicon hardware

Architecture

Small native programs, compiled for the Mac they run on.

100% Offline Privacy

Glass Shield and SiliconSense do not open a network connection. Telemetry, authentication, and the screen cover all stay on the Mac.

Native Swift & C Performance

The apps are compiled Swift and C. They are Mac processes, not a browser shell wrapped around a remote page.

Hardened Binary Protection

What ships is a signed application. Control values are compiled into each build instead of being published beside it.
